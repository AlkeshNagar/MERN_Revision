# MERN Revision Notes 

This repository contains my personal revision notes and code snippets for **JavaScript and MERN stack concepts**. It is organized topic-wise to help me revise fundamentals, intermediate concepts, and advanced JavaScript features used in real-world React and Node.js applications.


 ## Current Structure

- **JavaScript/** 
  - `foundation.js` — Variables, loops, functions, execution context, stack & heap, shallow/deep copy.


- **arrays-objects/**
    - `arrays.js` — Array methods and destructuring.
    - `objects.js` — Objects, methods, destructuring, immutability. 
    - `additional-things.js` — Spread/rest, template literals, optional chaining, nullish coalescing. 
    - `deepdive_objects.js` — `this`, `call`, `apply`, `bind`, prototypes. 

- **classes/** 
    - `classes.js` — Classes, inheritance, prototypes, getters & setters. 

- **functions/** 
    - `functions.js` — Closures, callbacks, higher-order functions, promises, callback hell, pure/impure functions, immutability, built-in HOFs. 


## Purpose 

    - Revise JavaScript from **basics to advanced**
    - Strengthen concepts required for **React, Node.js, and Express** 
    - Keep concise notes and examples for quick interview revision
    - Track daily learning progress during MERN revision This repository is primarily for **personal learning and interview preparation**.
